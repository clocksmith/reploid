## Delivered changes

Doppler owns one public generation definition and generated declarations.
Reploid bundles its public validator through `doppler-runtime-service.js`;
hand-maintained generation option lists are removed. Completed outputs preserve
raw text, token IDs, resolved settings, model identity and actual stopping
reason. Cancellation, stale attempts and invalid settings cannot produce an
accepted completed record.

The shared scalar sampler applies repetition then presence penalty within the
requested window, and top-k then normalized top-p. GPU penalties no longer race
when a history repeats token IDs. A physical diagnostic also exposed the old
GPU partition-max approximation discarding valid top-k candidates. Exact
partition heaps and top-p filtering replace it, including top-k zero and values
above the former fixed candidate limit. F16 logits now retain F32 candidate and
probability accumulation. The changed shaders have new digests; old Capsule
pins and earlier passing receipts are not rewritten or promoted.

Doe's goals, strategy contract, thesis, charter and live status now order the
seven requested target journeys: ordinary Node substitution first, interactive
reuse second, researcher acceleration third; frameworks, equipment vendors,
AMD and Qualcomm extend the same runtime. This is priority/documentation work,
not completed demonstrations, customers, supported new platforms, or measured
application advantage.
