Component: Node GPU host lifetime. Intent preserved: explicit cleanup settles owned work before releasing the provider. Boundary effects: close now waits for the captured owned device's `lost` promise after queue completion and pool/device destruction; the provider remains reachable until that completion.

This source repair uses the actual completion promise, not sleep or forced GC.

A 10,000ms close bound covers opening settlement and retirement. Timeout/rejection preserves provider globals and the captured device; new opening is refused. Unknown or rejected loss cannot authorize release. A later runtime-global device cannot substitute for the captured owner. An overdue retirement may finish, but provider release still requires the explicit successful close retry.
