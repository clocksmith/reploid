operator qualification. Source base: `5f36441dbf209da6e34991a50bf71362b6634a92`,
with the source changes retained in the accompanying archive.

## Reproduced boundaries

- The Run interface stopped on an empty room and its manual fallback enabled
  public contribution. It now uses the existing local Capsule executor for an
  ESM-2 request under the default policy when discovery or transport finds no
  available provider and WebGPU exists. Manual local execution also stays local.
- This does not start a provider, change participation preferences, or create
  contribution-resume intent. Canary, redundant, and quorum policies are not
  replaced by local execution. Invalid peer receipts do not trigger fallback.
- Local completion retains its Capsule operation receipt and separate policy
  label. It is not a countersigned peer receipt or independent comparison.
  Recent jobs and reload preserve that distinction. Existing publication
  permission checks remain unchanged.
- The desktop hero's two-column grid left nearly half the content width beside
  the form. Work is now centered beneath a compact diamond and wordmark.
  Navigation uses the power-tower mark instead of repeating the product name.
  Focus and run state drive the mark and diamond; reduced motion disables motion.
