# CATSCAN: Reploid Browser Library

Parent: [Reploid](../../CATSCAN.md)

## Target

Implement Reploid's distributed intelligence network through reusable agents,
models, memory and computation. Standalone usefulness belongs to participants.

## Authority

Owns algorithms, lifecycle, protocols and enforcement. Hosts own credentials,
permissions, model sessions, isolation and activation. Doppler defines valid
partitions and mathematics; Reploid places eligible work without changing semantics.

## Scope

Package source, declarations, schemas and assets.

## Contracts

Inputs: validated JSON configuration and injected host ports.
Outputs: explicit ESM exports, createReploid({ config, ports }), resolveConfig(),
distinct assignment/swarm protocols and signed rsi.improvement-episode/v1 evidence.

## Invariants

- Imports are inert; no application/server dependencies or page-global credentials.
- JSON owns policy; JavaScript orchestrates; Doppler computes.
- Isolate instance state/resources/configuration; close owned resources, never borrowed ones.
- Configuration cannot broaden authorization. Custody, execution and candidate sharing require distinct grants.
- Bayesian decisions retain priors, uncertainty, observation dependencies, provenance and costs.
- Freeze objectives, workloads, thresholds and independent evaluator identities before generation.
- Candidates cannot control evaluators, self-approve, erase failures or change grants.
- Granted adaptation/adoption are CI-independent. Mechanism changes require protected evaluation; weight changes require separate evaluation.
- Migration preserves protocols; extraction, ancestry and adoption are not capability proof.

## Acceptance

Compare strongest feasible local and equivalent centralized resources, counting
communication, verification, failures and human intervention.
Evidence: [package acceptance](../../tests/library-package-acceptance.js), matching
application/installed consumers, retained reports and [matrix](README.md).

## Non-goals

Hosting, routes, catalogs, domain workflows or Simulatte integration.

## Freedom

Preserve boundaries and recorded contracts.
