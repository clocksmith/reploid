# CATSCAN: Poolday Evidence Runtime

Parent: [Browser Runtime](../CATSCAN.md)

## Target

Coordinate authorized storage/compute and evaluated intelligence; adjudicate public-protein evidence.

## Authority
- Owns admission, assignment, recovery/accounting integration.
- Composes transport/jobs/custody with host policy; swarm stays distinct.
- Doppler owns Pack integrity/partitions/math; Reploid places eligible work.
- Cannot grant disclosures/adoption or own relays.

## Scope

- Subtree.

## Invariants
- Receipts prove signed records only.
- Adapters own comparisons; networking remains generic.
- JSON owns policy; Doppler owns math; Bayesian placement tracks costs/provenance.
- Private inputs require disclosure; custody grants no execution.
- Archive and decision memory remain distinct.
- Agreement/context prove no truth; reuse requires review.
- Duplicates count once; corrections/revocations supersede.
- Hosted v2 signs current agreement/attempt/economics. Member URLs and signing
  timestamps never reprice committed decisions. Deploy matching server before
  browser; never downgrade on verification rejection. Peer/forecast retain v1.
- Candidates authorize nothing; remain outside memory.
- Numeric uncertainty needs versioned methods/vector metrics.
- Imports never establish truth.
- Campaigns order disagreement, never volume/biological priority.
- Scientific-policy: Zero proposes; X evaluates cohorts; Poolday admits.
- Value requires approved actions/outcomes/causality/acceptance.
