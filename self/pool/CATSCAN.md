# CATSCAN: Poolday Evidence Runtime

Parent: [Browser Runtime](../CATSCAN.md)

## Target

Compose Reploid's intelligence network via Poolday: authorized storage, compute, evaluated coordination; adjudicate public-protein evidence.

## Authority
- Owns admission, assignment, recovery and accounting integration.
- Composes package transport/jobs/custody with host policy. Swarm stays distinct.
- Doppler owns Pack integrity, executable partitions/math; Reploid places eligible work.
- Cannot grant disclosures/adoption or own relays.

## Scope

- Subtree.

- Forecasts reuse [assignments](peer-assignment.js), signatures, acceptance; applications review, not admit.
- [Jobs](peer-pack-job.js), [acceptance](peer-pack-episode.js): pins, public consent, bounds.

## Invariants
- Receipts prove signed records only.
- Adapters own comparisons; networking remains generic.
- JSON owns policy; Doppler owns math; Bayesian placement tracks costs and provenance.
- Private inputs require disclosure; custody grants no execution.
- Archive and decision memory remain distinct.
- Agreement/context never prove truth; reuse requires review.
- Duplicates count once; corrections/revocations supersede.
- Candidate actions authorize nothing; remain outside memory.
- Numeric uncertainty requires versioned methods and vector metrics.
- Imports never establish truth.
- Campaigns order disagreement, not volume/biological priority.
- Scientific-policy: Zero proposes; X evaluates cohorts; Poolday admits.
- Value requires approved actions, outcomes, causality, and acceptance.
