This design proposed a scratchpad file (`/core/scratchpad.md`) that the agent rewrote each cycle as working memory. That file does not exist. Working, episodic and semantic memory are handled by `self/core/memory-manager.js`, described in [0x000068](0x000068-hierarchical-memory-architecture.md).
